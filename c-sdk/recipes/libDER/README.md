# libDER types

Install the two pinned XNU headers required by the Apple OSS Security
umbrella's `oids.h`. The types form part of the public Security
declarations. The XNU source carries both as external headers. The
macOS 26.5 public SDK paths were verified, and a public XNU install
rule for these two paths remains unlocated.

[Pinned XNU external headers](https://github.com/apple-oss-distributions/xnu/tree/ac9718fb1af618d5ce8678d0dc6e8a58f252216f/EXTERNAL_HEADERS/libDER)
